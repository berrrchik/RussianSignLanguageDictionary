# RussianSignLanguageDictionary — iOS-словарь русского жестового языка с видео и офлайн-кешем

> Приложение помогает изучать русский жестовый язык через словарь, категории и уроки: быстрый поиск, видео-демонстрации, избранное и поддержка офлайн-сценариев при нестабильном интернет-соединении.

---

## О проекте

**RussianSignLanguageDictionary** объединяет словарь жестов, обучающие материалы и практичные сценарии повседневного использования.  
Приложение фокусируется на скорости доступа к контенту: локальный кеш, гибридный поиск и офлайн-поведение позволяют продолжать обучение даже при проблемах с интернетом.

## Основные функции

- **Словарь жестов:** просмотр жестов с видео-демонстрациями и детальными карточками.
- **Гибридный поиск:** точные текстовые совпадения + семантический SBERT-поиск при наличии сети.
- **Навигация по категориям:** структурированный просмотр словаря по тематическим разделам.
- **Экран жеста с видео:** поддержка одного или нескольких видео для одного жеста.
- **Синонимы и связи:** переходы между связанными жестами для расширенного изучения.
- **Раздел уроков:** обучающие материалы и видео в отдельном образовательном потоке.
- **Избранное:** сохранение жестов с локальными snapshot-данными для быстрого доступа.
- **Офлайн-подготовка видео:** долговременный кеш избранных видео для просмотра без сети.
- **Устойчивость к сети:** cache-first загрузка данных и fallback-сценарии при недоступности backend.
- **Мониторинг:** аналитика, crash reporting и performance monitoring.

## Пользовательский интерфейс

Интерфейс построен вокруг ключевых разделов приложения:

- **Поиск** — быстрый ввод запроса, результаты и переход к карточке жеста.
- **Категории** — обзор тематических групп и списков жестов внутри них.
- **Уроки** — обучающий контент с видео и навигацией по материалам.
- **Избранное** — персональная подборка жестов с офлайн-готовностью.
- **Настройки** — информация о приложении, партнёрах и управление кешем.

## Особенности реализации

- `SwiftUI + MVVM` для разделения UI и бизнес-логики экранов.
- `Repository Pattern` как единый слой доступа к данным и кешу.
- Ручной `Dependency Injection` через `DIContainer` и `AppDependencies`.
- `SyncData` как общий snapshot словаря, категорий и уроков.
- Разделение видеокеша:
  - `video_short_term_cache` для обычного просмотра;
  - `favorites_videos` для офлайн-избранного.
- Сервисы инфраструктуры:
  - `HybridSearchService` и `SBERTSearchService`;
  - `VideoCacheService` и `CacheService`;
  - `NetworkMonitor` для контроля connectivity.
- Наблюдаемость через `Firebase Analytics`, `Crashlytics` и `Firebase Performance`.
- Тестируемая архитектура с unit, integration и UI тестами.

---

## Конфиденциальность

- Пользовательские данные и кеш сохраняются локально на устройстве.
- Сетевые запросы выполняются только для синхронизации и получения контента.
- Аналитика и диагностика используются для стабильности и качества приложения.
- Приложение не требует передачи пользовательских данных в сторонние рекламные SDK.

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone <repository-url>
   cd RussianSignLanguageDictionary
   ```
2. Открыть `RussianSignLanguageDictionary.xcodeproj` в Xcode.
3. Выбрать scheme `RussianSignLanguageDictionary` и подходящий iOS Simulator.
4. Запустить приложение через Run в Xcode.

## Запуск тестов

### Через Fastlane

```bash
bundle install
bundle exec fastlane tests_ci
```

```bash
xcodebuild test \
  -project RussianSignLanguageDictionary.xcodeproj \
```
